# StreamFlix Content Analytics & Executive Dashboard

## 📊 Project Overview
An end-to-end data analytics and business intelligence initiative engineered to clean, analyze, and visualize over nine years of streaming activity (~1M rows) for the subscription video-on-demand (SVOD) platform, StreamFlix.

## 📁 Repository Deliverables
*   `Phase1_Phase2_DataCleaning_EDA_Jenitha_P.ipynb`: Python notebook executing complete data sanitization, programmatic logical stress tests, and exploratory visualizations.
*   `Phase3_KPI_Calculations_Report.xlsx`: Core calculations ledger verifying business health frameworks and cohort lifecycle dynamics.
*   `StreamFlix_Content_Analytics_Jenitha_P.pbix`: Interactive 5-page Power BI dashboard modeled on a robust relational star schema.
*   `StreamFlix_Management_Summary_Report.docx`: Deep-dive executive analysis and strategic expansion suggestions addressed to the CEO.

## 📐 Business Intelligence Dashboard Layout
The attached Power BI application features 5 distinct, high-impact sheets designed for specific corporate insights:
1.  **Engagement Overview:** Evaluates top-level volumetric runtime trends and baseline user retention health.
2.  **Content Performance:** Cross-references total genre popularity scales directly against narrative completion depth.
3.  **Subscriber Insights:** Traces active subscription plan segments against global billing clusters.
4.  **Experience & Sentiment:** Identifies streaming hardware device trends matched against natural language sentiment review metrics.
5.  **Catalogue & Investment:** Audits the hour-volume returns on StreamFlix Originals vs. third-party licensed media property portfolios.
